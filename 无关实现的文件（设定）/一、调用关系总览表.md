| **模块5** LevelManager        | 模块3 StatusEffectManager | `add_status(Entity* target, string id, int duration)`        | 剧情强制添加状态                      |
| **模块5** LevelManager        | 模块4 InventoryManager    | `add_money(int amount)`                                      | 战斗结算发放金钱                      |

### 二、各模块依赖方向（箭头表示"依赖/调用"）

复制

```
模块5 (关卡流程)
  ├──→ 模块1 (启动战斗)
  ├──→ 模块2 (发放符咒)
  ├──→ 模块3 (剧情状态)
  └──→ 模块4 (发放奖励)

模块1 (战斗引擎)
  ├──→ 模块2 (触发符咒)
  └──→ 模块3 (状态查询/更新)

模块2 (符咒系统)
  └──→ 模块3 (添加/移除Buff)

模块4 (背包系统)
  ├──→ 模块1 (玩家属性修改)
  └──→ 模块3 (道具施加状态)

模块3 (状态系统)
  └──→ 模块2 (回调通知)
```

### 三、关键接口一致性要点

| 接口                                   | 声明方 | 调用方  | 签名匹配       |
| -------------------------------------- | ------ | ------- | -------------- |
| `trigger_talisman(int, Entity*) → int` | 模块2  | 模块1   | ✅ 返回int伤害  |
| `add_to_backpack(int)`                 | 模块2  | 模块5   | ✅ 参数int      |
| `add_status(Entity*, string, int)`     | 模块3  | 模块4/5 | ✅ 参数类型一致 |
| `has_status(Entity*, string) → bool`   | 模块3  | 模块1/2 | ✅ 返回bool     |
| `start_battle(vector<Enemy*>&)`        | 模块1  | 模块5   | ✅ 参数类型一致 |
| `add_money(int)`                       | 模块4  | 模块5   | ✅ 参数int      |
| `add_item(string, int) → bool`         | 模块4  | 模块5   | ✅ 返回bool     |
